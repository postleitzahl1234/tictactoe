# Sound files (optional)

No audio is shipped with this repository. To get sound, put your own files here:

| File | Played when |
|------|-------------|
| `background.mp3` | a game starts (loops) |
| `win.mp3` | you beat the bot |
| `lose.mp3` | the bot wins |

Missing files are skipped silently. Only use audio you are allowed to redistribute
if you commit it.
